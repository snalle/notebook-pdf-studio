# MVP Plan

## Goal
Turn an existing Jupyter notebook into a polished digital or printable PDF using a visual editor.

## Core user flow
1. Open `.ipynb`
2. See notebook blocks
3. Adjust layout and styling
4. Control page breaks and code splitting
5. Preview real pages
6. Export PDF
7. Save layout config

## Must-have features
- Markdown rendering
- Python code rendering
- Syntax highlighting
- Show/hide code
- Show/hide output
- Figures
- Basic tables
- A4 / Letter
- Portrait / landscape
- Margins
- Page breaks
- Code pagination controls
- Manual code line breaks
- Basic theme controls
- Digital / Print profiles
- PDF export
- Save `.nbpdf.json`

## Nice-to-have after MVP
- Undo/redo
- Multi-select
- Style copy/paste
- Table header repetition
- TOC
- Headers/footers
- More themes
- Desktop packaging

## Not in MVP
- Execute notebook cells
- Edit Python code
- Collaboration
- Cloud accounts
- Arbitrary Jupyter widgets
- Word/PowerPoint export

## MVP success criteria
The user can:
- Open a notebook
- Select a code block
- Change its styling
- Decide whether it splits across pages
- Insert a manual split between code lines
- Resize a figure
- Switch to print preview
- Export a PDF that matches the preview
